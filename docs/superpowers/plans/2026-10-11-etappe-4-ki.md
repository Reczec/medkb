# Etappe 4 – KI-Funktionen – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Rollenabhängige KI-Erklärungen, Zusammenfassungen, quellengebundene Fragen und prüfbare Admin-Entwürfe ergänzen; Cache und Tageslimits schützen die Demo.

**Architecture:** `app/ai/` trennt OpenAI-kompatiblen Provider, Prompts, Cache, Quoten und Ausführung. `/api/ai` liefert JSON oder SSE (`token`, `done`, `error`). Ein gemeinsamer Frontend-Client verarbeitet Streaming; KI-Ansichten bleiben getrennt von Inhalt und regelbasierter Klassifikation.

**Tech Stack:** bestehendes FastAPI/SQLAlchemy/httpx und React/TypeScript; keine neue Produktabhängigkeit.

**Spec:** [v2 §4–5, §7–10](../specs/2026-10-10-medkb-v2-design.md), [PRODUCT](../../../PRODUCT.md), [DESIGN](../../../DESIGN.md). Der Nutzer hat die nächste Etappe samt Dokumentation ausdrücklich zur Umsetzung beauftragt; bestehende Spezifikation und native Ausführung werden fortgeführt.

## Global Constraints

- Deutsche UI, englischer Code/API; „Prototyp mit Beispieldaten – keine medizinische Beratung.“ bleibt sichtbar.
- Keine Patientendaten, individuellen Diagnosen oder Dosierungsempfehlungen. Kontext und Modellantworten sind nicht vertrauenswürdige Instruktionen.
- `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`; ohne Key HTTP 503 `ai_not_configured`. Modell austauschbar; offizielle Provider-Dokumentation bei Planung prüfen.
- Gehashte direkte Client-IP (keine selbst ausgewerteten Forwarded-Header), 30 ungecachte Aufrufe/UTC-Tag/Client; `AI_DAILY_LIMIT=500` global. Proxy-Vertrauen gehört zur Serverkonfiguration in Etappe 5.
- Cache mit Feature, Dokument-ID, Inhaltsfingerprint, Modell, Provider und Rolle; keine Cache-Einträge für Fehler/abgebrochene Streams; `ask` ungecacht. Begonnene Provider-Aufrufe verbrauchen Quota auch bei Fehlern.
- Tests ausschließlich Fake-Provider/gemocktes HTTP. Pro Task vollständiges pytest, Ruff check/format und frontend lint/typecheck/test/build/e2e. Ein Commit pro Task; Änderungen und Entscheidungen in dauerhaftem Abschlussbericht.

## Review Focus

1. Gleichzeitige Quota-Reservierungen am Tageslimit: globale und Client-Zähler atomar, keine teilweise verbuchte Anfrage.
2. Fehlerhafte/abgebrochene Provider-Streams und getrennte UTF-8/SSE-Frames: kein erfolgreicher Teil-Cache, UI zeigt Fehler und lässt Retry zu.
3. Gleiche IDs nach Demo-Reset/Archivrestore oder geänderte Inhalte/Rolle/Modell: kein fremdes Cache-Ergebnis.
4. Halluzinierte Quellenmarken und manipuliertes Kontextmaterial: nur serverseitig gefundene Einträge als Quellen, ungültige Marken abweisen; keine beliebigen URLs vom Modell.
5. Ungültige generierte Entwürfe/ICD-Codes/Kategorien: gegen vorhandene Schemas validieren, nie automatisch speichern oder Regeln überschreiben.

## File map and shared interfaces

- `app/ai/provider.py`: `AIProvider.complete(messages: list[dict[str,str]]) -> str`, `stream(messages) -> AsyncIterator[str]`; `get_provider(settings)` Dependency, `AIUnavailable`.
- `app/ai/store.py`, `app/models.py`, `app/config.py`: `cache_key(feature, document_id, inputs, role, settings) -> str`, `read_cache(db,key) -> dict|None`, `write_cache(db,key,feature,document_id,settings,result)`, `reserve(db,client_id,settings)`, `usage_today(db) -> int`; `AICache`, `AIUsage`.
- `app/ai/schemas.py`, `prompts.py`, `service.py`, `app/routers/ai.py`: typed requests, constrained model-output validation, source references, execution/SSE; HTTP router with role dependencies.
- `app/sources/pubmed.py`: `fetch_abstract(client,pmid,settings) -> str|None` from NCBI efetch XML with existing throttle. `app/ai/prewarm.py`: CLI document-cache warmup.
- `frontend/src/features/ai/`: streaming client, request hook, shared result sheet, document controls, grounded chat, editor helpers. Existing App/sidebar/patient-home/dashboard/document/editor integrate them.
- Tests: `tests/test_ai_provider.py`, `test_ai_store.py`, `test_ai_api.py`, permission matrix; frontend AI client/view tests, Playwright flows.
